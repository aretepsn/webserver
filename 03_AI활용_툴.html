  • Hermes Agent

    • 오픈소스 자율형 개인 에이전트 프로그램 (Nous Research, 2026.02 공개, MIT 라이선스)

    • 내 PC나 서버에 설치하여 도구 실행, 메모리 저장, 스킬 학습 등을 수행하는 개인용 비서입니다.

    • 이름 유래 : 그리스 신화의 전령의 신 헤르메스. 메시지를 받아 대신 일을 처리하고 결과를 전달하는 "심부름꾼" 역할에서 따온 이름.

    • 정체 : 웹서비스가 아닌 파이썬 CLI 프로그램. pip install hermes-agent 한 줄로 설치되며 별도 서버/DB 불필요.

    • AI API 연결 : Hermes 자체는 AI 모델이 아님. Claude, GPT, Gemini, DeepSeek 등 API 키를 꽂아 사용하거나 Ollama 로컬 모델 연결.

    • 동작 흐름

      ① hermes chat : 터미널에서 대화 (Claude Code와 유사)

      ② hermes gateway : 백그라운드 상주 → Telegram / Discord / Slack 등 16개+ 메신저에서 지시 → 내 PC에서 파일·스크립트·셸 명령 실행 → 결과 메신저로 회신

      ③ 크론 예약 작업 ("매일 아침 8시에 뉴스 요약") 자동 실행

    • 자기 개선 : 작업을 끝내면 과정을 스킬 파일로 저장 → 비슷한 작업 시 재사용. 세션이 끝나도 사용자·프로젝트 맥락을 영구 메모리에 유지.

    • Docker 사용 이유 : 리눅스/맥 기준으로 만들어져 Windows에서는 Docker(또는 WSL)로 리눅스 컨테이너 안에서 실행. 셸 명령을 실행하는 에이전트이므로 컨테이너로 격리하면 보안상 안전. AWS EC2(리눅스)에 올릴 경우 Docker 없이 pip로 바로 설치 가능.

    • 비용 (API 종량제, $1 ≈ 1,400원 기준)

      Opus 5 : 입력 $5 / 출력 $25 (100만 토큰당) · Sonnet 5 : $2 / $10 · Haiku 4.5 : $1 / $5

      단순 질문 1회 ≈ 13~32원이지만, 에이전트는 작업 1건에 API를 10~50회 호출 → Opus 기준 작업당 약 5,000원, Sonnet 기준 약 2,000원 (캐싱 시 1/3~1/5)

      $20 Pro 요금제(정액)로는 연결 불가, API 키 필수. 상주 에이전트는 Sonnet 5로 시작하고 콘솔에서 월 사용 한도 설정 권장.

    • 주의 : 게이트웨이가 도는 PC가 켜져 있어야 동작 (24시간 운영 시 EC2 등 서버 필요). 메신저 봇 허용 사용자 ID를 반드시 제한할 것.
