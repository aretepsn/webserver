AI 클로드 × GPT 콜라보

API 과금 없음Claude가 만들고, GPT가 검토하고, Claude가 고치는 반복 루프를 구독 계정만으로 돌리는 방법과 GitHub에 공개된 도구 모음

1. 하려는 것 — 생성자·검토자 루프

두 AI를 그냥 붙여놓는 게 아니라, 흐름을 돌리는 "심판" 역할(오케스트레이터)이 한쪽의 출력을 다른 쪽의 입력으로 넘겨주는 구조입니다. 사용자는 처음 명령 한 번만 내리고, 사용자 결정이 필요한 항목만 마지막에 질문으로 받습니다.

  • 사용자

    명령 1회 입력완료 기준(acceptance criteria)을 함께 주면 루프가 잘 수렴함

  • Claude

    ① 결과물 v1 작성코드·문서·기획서 등 파일로 저장

  • GPT
    ② 결과물 검토 → 미비사항을 JSON으로 출력검토 결과(status)에 따라 세 갈래로 나뉨
    • approved종료 · 사용자에게 결과 전달
    • needs_user_decision루프 중단 · 질문 목록을 사용자에게
    • needs_work③으로 → Claude가 수정
  • Claude

    ③ 미비사항 읽고 처리 → 결과물 v2

  • 제어

    ④ 다시 ② … 최대 N회 반복보통 2~3회에서 수렴. 미비사항이 줄지 않으면 중단

검토 결과 형식 예시

GPT의 리뷰를 자유 텍스트로 받으면 스크립트가 판단을 못 하므로 구조화된 형식을 강제합니다.

{
  "status": "needs_work" | "approved" | "needs_user_decision",
  "issues": [
    {"severity": "high",   "description": "...", "auto_fixable": true},
    {"severity": "medium", "description": "...", "auto_fixable": false,
     "question_for_user": "..."}
  ]
}

2. API 대신 CLI — 구독으로 처리하는 원리

웹 채팅(claude.ai, chatgpt.com)을 자동화하는 건 안 되지만, 각 회사의 공식 CLI 도구는 구독 계정으로 로그인해서 쓸 수 있고, 스크립트에서 호출이 가능합니다.

Claude 쪽GPT 쪽
도구Claude CodeCodex CLI — npm i -g @openai/codex
로그인Claude Pro / Max 구독 계정ChatGPT Plus / Pro 구독 계정 (codex login)
과금구독료에 포함, 별도 과금 없음구독료에 포함, 별도 과금 없음
비대화형 실행claude -p "명령"codex exec "명령"

둘 다 "프롬프트 넣으면 결과 출력하고 종료"하는 모드가 있어서, 번갈아 호출하는 루프를 만들 수 있습니다. 가장 간단한 구성은 별도 스크립트 없이 Claude Code 세션 하나 안에서 Bash로 codex exec를 "외부 리뷰어 도구"처럼 호출하게 하는 것입니다. 이걸 스킬(.claude/skills/review-loop/)로 만들어두면 /review-loop 결과물.md 한 줄로 실행됩니다.

4. 공통 동작 원리

  • Claude Code가 결과물 작성

  • Bash로 codex exec "..." 호출 — ChatGPT 구독 계정으로 codex login이 되어 있음

  • Codex 출력(마크다운/JSON)을 Claude가 읽고 수정

  • 훅(Stop hook) 또는 스크립트가 라운드 수·승인 여부를 보고 반복/종료

Codex 쪽은 ChatGPT 계정 로그인, Claude 쪽은 Claude Code 자체 구독이라 API 과금 없이 동작합니다. 역방향(Codex가 주도하고 Claude가 리뷰)도 claude -p를 호출하면 똑같이 가능합니다.

5. 추천 및 설치

코드 개발 결과물 검토

기획서 / 설계문서 검토

promptadvisers/claudex — 라운드마다 다른 관점으로 압박 검토

저장소 클론 → install.sh → codex login → .claude/plugins/에 복사 → /claudex:doctor로 확인

사전 준비 (공통)

codex --version              # 설치 여부 확인
npm i -g @openai/codex       # 없으면 설치
codex login                  # ChatGPT 구독 계정으로 로그인

프로젝트 파일 안에 두고 직접 커스터마이징하고 싶으면 위 프로젝트 중 하나의 SKILL.md를 참고해서 자체 스킬을 작성하면 됩니다.

6. 주의할 점

구독에도 사용량 한도는 있다

  • Claude Pro/Max, ChatGPT Plus 모두 5시간 단위 사용량 창(rate limit)이 있음

  • 루프는 매 반복마다 결과물 전체를 다시 읽으므로 사용량을 빨리 소모. 기본 등급으로 큰 결과물 5회 반복이면 한도에 걸릴 수 있음

  • "무료로 무제한"이 아니라 "이미 낸 구독료 안에서"

하면 안 되는 것

  • 브라우저 자동화(Selenium/Playwright)로 claude.ai / chatgpt.com 채팅창 조작 → 양쪽 모두 이용약관 위반, 계정 정지 사유. 잘 깨지기도 함

  • 구독 로그인 토큰을 추출해서 API처럼 직접 호출 → 마찬가지로 약관 위반

  • 공식 CLI를 공식 로그인으로 쓰는 것만 안전

설계 시 꼭 정할 것

  • 종료 조건 — 최대 반복 횟수, "미비사항 없음" 판정, 연속 2회 미비사항이 줄지 않으면 중단

  • 검토 기준 명시 — 리뷰어는 지적할 게 없어도 지적하는 경향이 있으므로, 완료 기준을 주고 그 기준 대비로만 검토하게 해야 수렴

  • 사용자 결정 분리 — "이 방향이 맞는가" 같은 주관적 판단은 두 AI가 핑퐁하기 쉬우므로 needs_user_decision으로 빼서 사용자에게

  • 결과물 종류 — 두 CLI 모두 코딩 에이전트라 파일 기반 작업(코드·문서·마크다운)에 최적. 파일로 저장할 수 있는 결과물이면 무엇이든 가능
