## index.html (자료 목록)

`index.html`은 이 저장소의 **파일·폴더를 한 줄 설명으로 모아 놓은 목록 페이지**입니다. PC와 모바일 모두에서 볼 수 있습니다.

- **목록에 올리는 대상**: 루트에 있는 html 페이지, 그리고 `index.html`이 들어 있는 하위 폴더
- **항목마다**: 제목 + 한 줄 설명 + 경로
- **클릭 동작** (모두 같은 화면에서 열림, 새 탭 아님)
  - 파일 항목 → 해당 html 페이지로 이동
  - 폴더 항목 → 그 폴더의 `index.html`로 이동 (폴더 목록 페이지에는 "상위 목록" 링크가 있어 되돌아올 수 있음)
- 파일 항목 옆 **프롬프트** 버튼 → 그 페이지를 다시 만들 때 쓰는 지시문(`*_프롬프트.md`)
- 링크는 모두 상대경로라 폴더째 옮겨도 동작합니다.

### 항목 추가 방법

- **페이지 추가**: html 파일을 루트에 두고, `index.html`의 "페이지" 목록에 `<li class="item">` 한 개를 추가
- **폴더 추가**: 폴더 안에 `index.html`을 만들고(`sample_spec/index.html` 참고, "상위 목록" 링크 포함), 루트 `index.html`의 "폴더" 목록에 `<li class="item folder">` 한 개를 추가
- 추가 후 푸터의 페이지·폴더 개수와 위 표를 함께 고칩니다.
