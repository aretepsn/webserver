개발 방법론 정리

  • SDD

    Spec-Driven Development

    명세 기반 개발

    개발 명세서(Spec)를 먼저 작성하고, AI가 그 명세를 기준으로 코드를 생성하게 만드는 개발 방식

  • TDD

    Test-Driven Development

    테스트 주도 개발

    코드를 작성하기 전에 실패하는 테스트 코드를 먼저 작성하고, 이를 통과하는 최소한의 코드를 구현하는 방식

  • BDD

    Behavior-Driven Development

    행위 주도 개발

    "사용자가 버튼을 클릭하면 ~게 동작해야 한다"처럼 사용자의 행위와 시나리오(Given-When-Then)를 중심으로 명세를 작성하고 개발하는 방식

  • DDD

    Domain-Driven Development

    도메인 주도 개발

    비즈니스 핵심 영역(도메인)의 용어와 모델을 정의하고, 이를 중심으로 시스템을 설계/개발하는 방식
