# <프로젝트명> 스펙 문서 (spec)

<한두 문장: 무엇을 하는 프로젝트인가 · 누가 쓰나>

> 이 파일은 **프로젝트 구조 정의서**입니다. `/src-init` · `/src-update` 는 폴더 이름을 모른 채 이 파일의 「구성」 · 「기술 · 실행」 · 「프로젝트 고유 지시」 절을 읽어 동작합니다. 절 제목을 바꾸지 마세요.

## 정본 규칙

- **이 `spec/` 폴더가 정본**입니다. src 는 이 문서대로 만들고, 구현하다 문제가 생기면 **이 문서를 고칩니다**(문서가 곧 결정).
- 상세 문서 한 장은 앞부분에 무엇 · 구성 · 흐름과 규칙(사람 말), `---` 아래에 구체 명세(입력 · 출력 · 오류 · 코드 위치 · 시험)를 적습니다.
- 「코드」 열은 `파일 함수명` 으로 적고 **줄 번호는 적지 않습니다** — 줄은 코드가 바뀔 때마다 밀려 지킬 수 없습니다.
- 결정이 필요한 것은 [03_정책_결정기록](00_시작/03_정책_결정기록.md) 「확인 대기」 에 적고, 결정되면 「결정 기록」 에 결론을 남기고 02_정책 과 해당 상세 문서를 고칩니다.

## 구성

폴더 번호가 곧 **src 를 만드는 차례**입니다. 「대응 src」 는 그 폴더의 명세가 구현되는 위치이며, `/src-update` 가 바뀐 spec 에서 고칠 src 를 찾을 때 씁니다.

| 차례 | 폴더 | 무엇 | 대응 src |
|---|---|---|---|
| 00 | [00_시작/](00_시작/) | 01_개요 · 02_정책 · 03_정책_결정기록 · 04_구현_지시문 · 05_구현_지시문_변경시 | (전체) |
| <10> | <10_설정/> | <무엇> | <src 경로> |
| <20> | <…> | <…> | <…> |
| <50> | <50_시험/> | <인수기준(전제 · 행위 · 기대) · 시험 코드> | <시험 코드 경로> |
| <90> | <90_운영/> | <배포 · 실행 · 백업 등> | <스크립트 경로> |

| 항목 | 값 |
|---|---|
| 프로젝트 종류 | <웹 · CLI · 임베디드 · 라이브러리 …> |
| 언어 · 버전 | <…> |
| 프레임워크 · 주요 의존성 | <…> — 여기 없는 기술을 쓰려면 먼저 묻고 승인받는다 |
| src 위치 | <src/ 또는 실제 코드 폴더 · 파일들> — `/src-init` 이 지우고 새로 만드는 범위 |

## 프로젝트 고유 지시

`/src-init` · `/src-update` 때 04 · 05 지시문에 더해 지킬 것입니다. 04 · 05 는 범용이라 고치지 않고, 이 프로젝트만의 규칙은 여기에 적습니다.

- <예: DB 표는 `20_데이터/도구/schema.sql` 로 세운다 · 운영 DB 에는 직접 쓰지 않는다>
- <예: 화면 모양 · 문구는 `40_화면/목업` 을 바꾸지 않는다>
- <없으면 「없음」>

## 변경으로 보지 않는 것

`/src-update` 가 바뀐 파일을 찾을 때 구현 대상에서 뺍니다.

- 검토서 · 제안서(`*_suggest.md` 등) — 승인 전까지 구현 요구가 아닙니다. 채택한 내용은 정본 문서에 옮겨 적습니다.
- <생성물 · 결과물 · 사람이 남긴 실행 기록 등의 경로>

## 서로 어긋날 때

둘이 어긋나면 **위에 있는 것을 정본으로 보고 아래를 고칩니다.**

| 차례 | 자료 | 역할 |
|---|---|---|
| 1 | 00_시작/02_정책 · 03_정책_결정기록 | 업무 규칙의 정본 |
| 2 | <상세 명세 폴더들> | 규칙을 단위별로 푼 상세 명세 |
| 3 | <50_시험/> | 명세대로 되는지 보는 검증 자료 |
| 4 | <참고용 원형 · 초안이 있으면> | 참고용 — 동작의 근거가 아님 |

## 이 폴더로 src 를 구현하려면

처음은 `/src-init`([04_구현_지시문](00_시작/04_구현_지시문.md)), 그 뒤로 spec 을 고쳤을 때는 `/src-update`([05_구현_지시문_변경시](00_시작/05_구현_지시문_변경시.md)) 를 씁니다. 바뀐 곳은 git 으로 찾으며, 기준점은 첫 줄이 `spec 반영:` 인 가장 최근 커밋입니다.
