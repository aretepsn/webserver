## spec 이 정본이다

- 이 프로젝트의 구현 기준은 `spec/` 폴더다. 먼저 `spec/README.md` 를 읽는다 — 폴더 구성 · spec 과 src 의 대응 · 기술 · 실행 · 시험 방법이 거기 있다.
- src 는 spec 을 근거로만 만들고 고친다. **spec 에 없는 변경이 필요하면 spec 부터 고친다**(문서가 곧 결정). spec 에 없는 기능은 더하지 않는다.
- 구현하다 spec 과 어긋나거나 빠진 것, 두 가지로 읽히는 것이 나오면 임의로 정하지 말고 묻는다. 결정은 `spec/00_시작/03_정책_결정기록.md` 에 남기고, `02_정책` 과 해당 상세 문서에 결론을 적는다.
- spec 문서에서 코드를 가리킬 때는 `파일 함수명` 으로 적고 줄 번호는 적지 않는다.
- 명령: `/src-init`(spec 으로 처음부터 구현) · `/src-update`(바뀐 spec 만 반영).
- spec 을 반영해 src 를 맞춘 커밋은 첫 줄을 `spec 반영: <요약>` 으로 한다 — `/src-update` 의 기준점이다.
