sample_spec

spec 폴더를 정본으로 두고 모든 src를 spec에서 만드는 방식을 다른 프로젝트에 심는 샘플이에요. 항목을 누르면 이 화면에서 해당 문서가 열립니다.

설치 · 규칙

  • sample_spec 설치 대상 프로젝트 루트에 복사한 뒤 Claude Code로 설치하는 순서 SETUP.md
  • CLAUDE.md 에 덧붙일 규칙 설치 때 루트 CLAUDE.md에 추가하는 "spec이 정본" 규칙 CLAUDE_rules.md

명령어 (commands)

  • /src-init spec만 보고 src를 처음부터 구현하는 슬래시 명령 commands/src-init.md
  • /src-update spec이 바뀐 뒤 바뀐 곳만 src에 반영하는 슬래시 명령 commands/src-update.md

spec 템플릿 (spec_template)

  • 스펙 문서 README 프로젝트 구조 정의서 — 정본 규칙, 구성, 기술·실행, 고유 지시 spec_template/README.md
  • 01 · 개요 프로젝트의 목적, 사용자와 권한을 적는 틀 spec_template/00_시작/01_개요.md
  • 02 · 정책 프로젝트가 지켜야 할 규칙을 주제별로 근거와 함께 모으는 틀 spec_template/00_시작/02_정책.md
  • 03 · 정책 결정 기록 결정을 기다리는 규칙(확인 대기)과 결정된 규칙의 근거 spec_template/00_시작/03_정책_결정기록.md
  • 04 · 구현 지시문 (처음) spec만 보고 src를 처음 구현할 때 쓰는 범용 지시문 spec_template/00_시작/04_구현_지시문.md
  • 05 · 구현 지시문 (변경시) spec을 고친 뒤 git으로 바뀐 곳을 찾아 src에 반영하는 범용 지시문 spec_template/00_시작/05_구현_지시문_변경시.md
